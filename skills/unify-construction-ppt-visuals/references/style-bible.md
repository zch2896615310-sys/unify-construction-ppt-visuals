# 中建系工程技术标视觉圣经

## 1. 固定视觉令牌

| 类别 | 固定值 |
|---|---|
| 画幅 | 严格 2:1，默认 2000×1000 |
| 背景 | 白色至极浅蓝灰的低对比渐变，留白充足 |
| 深蓝 | `#005BAC` |
| 标准蓝 | `#0068D9` |
| 浅蓝 | `#EAF4FF` |
| 强调红 | `#E60012`，全套唯一红色 |
| 工程橙 | `#F59E0B` / 浅色 `#FFF4D6`；施工阶段、分区、机械 |
| 数字青 | `#0F9FA8` / 浅色 `#E6F7F7`；BIM、数字化、信息系统 |
| 验收绿 | `#2E9B65` / 浅色 `#EAF7F0`；完成、验收、达标 |
| 蓝灰 | `#64748B` / 浅色 `#F1F5F9`；次要信息、中性状态 |
| 正文 | 深蓝灰，不用纯黑大标题 |
| 图标 | 使用随 Skill 提供的同一套蓝色线性图标；24×24 视框、1.8px 等效线宽、统一视觉尺寸与底板 |
| 卡片 | 轻圆角、白底、细浅蓝描边、极轻冷灰阴影 |
| 标签 | 标准蓝底或浅蓝底；同层级同高度 |
| 摄影 | 写实、自然中性光、工程现场真实质感 |
| 装饰 | 克制的网格、细线、坐标点；不得喧宾夺主 |

推荐比例令牌：内容画布安全边距约宽度 3%，卡片间距约 1.2%，主内容区占安全框 100%。顶部与底部都不预留或生成表头、页眉、标题栏、企业标识、项目横幅、页码、页脚。同一套页面只使用一组比例。

这些是项目级视觉令牌，不等于页面模板。相同内容模式还必须使用 `template-registry.md` 中同一模板的精确坐标；不得把“约 3%”当作允许逐页漂移的区间。

若生成工具不支持原生 2:1，把关键内容限制在中央安全区，随后通过裁切或补边得到 2:1。保持原始比例，不进行非等比缩放。

### 配色占比与使用规则

- 中建蓝 + 白色 + 浅蓝灰必须占视觉面积 75%–90%，保持品牌主导。
- 彩色辅助色占 5%–12%，硬上限 15%；仅用于小标签、节点、细线、图标局部、数字底片或模型分区。
- 每页最多使用一种彩色辅助色；蓝灰视为中性色，可共存。照片中的自然色不计入界面配色数量。
- 强调红 `#E60012` 不属于辅助色，只表示关键数字、日期、风险或核心措施，面积通常不超过 5%。
- 先按语义选色，再按整套复用。禁止同一语义跨页换色，也禁止同一种颜色一会儿表示完成、一会儿表示风险。
- 没有明确语义时使用 `none` 或蓝灰，不要强行增加颜色。

推荐映射：

| 页面/内容 | 默认辅助色 |
|---|---|
| 施工部署、施工分区、机械设备 | 工程橙 |
| 专项方案、施工流程 | 工程橙或蓝灰，二选一 |
| BIM、智慧工地、数字平台 | 数字青 |
| 验收、交付、完成状态、质量达标 | 验收绿 |
| 项目概况、工期计划、通用信息 | 蓝灰或不使用 |
| 劳动力计划、工种投入矩阵 | 不使用辅助色；中建蓝呈现趋势与热力强度，唯一红只标峰值 |
| 风险与关键日期 | 仍使用唯一强调红，不新加风险色 |

## 2. 视觉身份

固定关键词：央企高端工程述标、现代、专业、数字化、精装品质、克制科技感、真实施工语境。

不属于该身份：霓虹赛博朋克、紫蓝渐变 SaaS 仪表盘、玻璃拟态、卡通插画、杂志拼贴、奢华金黑、红色政务展板、普通 Word 表格截图。

## 3. 页面槽位

以下槽位只用于首次分类。确定页面类型后，必须转入 `template-registry.md` 的固定模板；相似页面不得继续自由解释槽位。

### cover

仅生成封面所需的项目建筑主视觉内容，不生成企业标识、项目名称、汇报类型或任何表头文字；这些由用户自己的表头承载。

### overview

左侧统一宽度的字段标签；右侧内容边界完全对齐。大数字可做 2–4 个数据卡。文字很多时拆成“关键词 + 原文说明”，不删内容。内容直接从安全框顶部开始，不设置页面标题栏。

### deployment

左侧施工区域；中部真实三维模型/效果图；右侧文字说明；底部施工逻辑。分区色默认中建蓝与工程橙，仅用于模型区域标识，不扩展为整页主色。

### method

上部质量控制要点；左侧流程；右侧现场照片卡；底部固定控制主线。施工顺序必须先核实。照片卡使用相同宽高比、圆角与标签。

### bim

主视觉为 BIM 模型或应用场景，而非裸软件截图；一侧解释应用，底部总结管理价值。界面截图置于统一设备框或卡片内，可使用数字青作为唯一彩色辅助色。

### schedule

用同一基线的时间轴、里程碑或阶段卡。重点日期/天数用唯一强调红，不同时使用多种红色层级。

### risk

风险、措施、责任与结果形成明确映射。优先采用横向四列或闭环流程，不用大量警示色块。

### labor-workforce-plan

默认使用 `labor-workforce-plan-v1`：顶部管理结论与峰值卡，中部月度合计趋势，下部工种投入热力矩阵。该类页面强调数据分析，不添加装饰性图标；峰值卡、折线峰值和合计行峰值必须是同一个精确值。折线与热力矩阵共享中建蓝尺度，红色只标峰值，不把整页做成互联网数据大屏。

## 4. 图片规则

- 原项目效果图是事实源，不是灵感图。保留视角、结构、材质、空间关系和主体。
- 图片裁切遵循主体安全区；不得把关键建筑、设备或人员截断。
- 多张照片统一色温、曝光、对比度、圆角、标签和宽高比。
- 施工设备融合须满足透视、比例、落地点、接触阴影、遮挡关系和光向一致。
- 人物以真实工程人员为主；避免摆拍、夸张姿势、重复面孔和肢体异常。

## 5. 文字规则

- 保留所有原文与数字。允许分段、换行、分类、变成流程或卡片，但不得概括替代原文。
- 红色只用于少量关键数字、日期、节点或核心措施。
- 不用彩色 emoji 代替图标。
- 内容区小标题、正文、注释三级层级固定，不在单页临时发明字号体系。页面标题只作语义上下文，不渲染。

## 6. 图标硬规则

- 三个及以上重复模块/阶段、设备措施清单、施工区/楼层/班组映射必须使用图标；不得整页省略。
- 每个主要模块只放一个图标，图标用于识别语义，不作为装饰填空。
- 默认使用 `assets/icons/construction-line-icons.svg`；同一页面和同一系列不得混用其他图标库。
- 图标采用 24×24 视框、圆角端点、1.8px 等效线宽；常规颜色为中建蓝，施工分区/机械允许工程橙，完成/验收允许验收绿。
- 同层级图标的尺寸、底板、内边距和相对文字位置完全一致。推荐图标底板为 44–56px 的浅蓝圆角方形或蓝色圆形，单页只选一种。
- 图标与稳定语义一一对应；禁止同一图标跨页表示不同概念。完整映射与例外见 `icon-system.md`。
- 连续正文、精确矩阵或确实没有稳定隐喻时可以不用图标，但必须在语义账本中声明 `icon_plan: none` 及原因。

## 7. 禁用清单

紫色、粉色、暗红、酒红、大面积黄色、未经定义的新色、辅助色大面积铺底、单页多种彩色辅助色、跨页随机换色、彩色 emoji、卡通图标、厚重投影、强玻璃拟态、霓虹光、过度发光边框、随机圆角、不同图标库混用、页面表头、标题栏、企业标识、项目横幅、页码、页脚、漂浮居中大标题、无对齐依据的装饰、改变原图空间、自动补写施工事实。
