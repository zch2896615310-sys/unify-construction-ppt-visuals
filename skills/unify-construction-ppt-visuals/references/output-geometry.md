# 实际内容严格 2:1 与四边等距透明留白输出合同

本文件统一规定实际内容区域的比例、透明边距和验收方法；与其他参考中的画布比例、底色、百分比安全区或旧模板坐标冲突时，以本合同为准。用户当次明确指定其他比例、底色或出血方式时，按其指令执行并记录例外。

## 同时满足的输出条件

- 默认交付带真实 alpha 通道的 PNG。实际内容区域指所有 `alpha>0` 像素的联合包围盒，不是预先声明的内容框、内部卡片或画布。阴影、描边、抗锯齿边缘均计入；有整页外框时须包含完整外框，无整页外框时包含全部实际内容，不得为测量额外添加边框。
- 包围盒使用右、下不包含的坐标 `B=(left, top, right, bottom)`。其整数像素宽高为 `w=right-left`、`h=bottom-top`，必须严格满足 `w == 2*h`；不能用“接近 2:1”或最终画布 2:1 代替。
- “四边等距”指该包围盒到画布左、上、右、下四边共用同一个正整数像素边距 `m`：`left == top == W-right == H-bottom == m > 0`。不是四边各取自身方向的同一百分比，也不是卡片内部 padding 相等。透明留白中不得有阴影、杂点或低 alpha 残留。
- 最终画布由内容和边距推导：`W=w+2m`、`H=h+2m`，`B=(m,m,m+w,m+h)`。不单独要求 `W == 2*H`；在 `w==2*h` 且 `m>0` 时，画布比例自然小于 2:1，不得因此返工或压缩主体。
- 默认实际内容包围盒为 `2000×1000`；同系列沿用已确认的 `m`，未确认时使用 `m=round(w*0.03)`（须为正整数）。默认 `m=60`，最终画布 `2120×1120`，`B=(60,60,2060,1060)`。四边均为 60px；不能把 2000×1000 当成加留白后的画布尺寸。
- 框外及卡片之间无底板区域保持透明；卡片或内容底板可沿用白色及已确认的源图配色。不得用白色、黑色或棋盘格冒充透明。

## 生成与导出

1. 生成前明确内容尺寸 `w,h`、等距边距 `m`，再推导画布 `W,H` 与目标包围盒 `B`，将这组值写入整页 ImageGen 提示词；调用时设置 `transparent_background: true`。同类页面冻结同一组参数。
2. 让全部实际内容的外沿符合目标包围盒。通过行高、模块间距、换行和内部留白重排，保持文字、图标、照片正常比例以及所有事实和对应关系；不得非等比缩放、裁掉内容或加入大块无意义空白凑内容比例。
3. 旧模板的百分比坐标仅作构图基准，不代表最终画布坐标。首次适配时在 ImageGen 中将主体重排到严格 2:1 的实际内容包围盒，再外加等距透明边距，并冻结新的整数像素坐标；此后同类页面一致应用。所有 PrimaryFrame 共用 `left=m`、`right=m+w` 的像素对齐线，不继续套用最终画布的 3%/97%。保留劳动力、风险等模板的内部内容结构与已确认风格。
4. ImageGen 返回后读取真实像素与 alpha。可做不重绘内容的末端无损裁边、平移和透明补边；主体仍须来自整页 ImageGen，不能用代码重建页面。裁边只能移除透明空白或已核实的框外杂点，不得损伤外框、正文或抗锯齿边缘。需要改变主体布局时，继续用 ImageGen 定向重排。
5. 只对已满足 `w==2*h` 的实际内容包围盒进行等距补边：四边各加同一个正整数 `m` 即可，最终画布无需满足 2:1。若内容本身比例不符，增加透明像素无法改变它，必须返回 ImageGen 重排；不得用扩大透明画布、声明目标内容框或加测量外框冒充合格。
6. 几何修订保持原配色和内容，不反复叠加边框或阴影；每次再生成后重新核对文字、数字、图标与对应关系。

## 导出验收

运行只读检查器（依赖 Pillow）：

```powershell
python -X utf8 scripts/check_output_geometry.py "最终图片.png"
```

检查器以最终 PNG 中所有 `alpha>0` 像素计算包围盒，输出画布尺寸、内容包围盒、内容尺寸、四边像素距离及通过状态；比例检查对象仅为实际内容尺寸 `w,h`。可在诊断时用较高 alpha 阈值帮助定位主外框，但不能提高验收阈值以忽略残留像素、伪造透明或等距。几何检查不替代人工内容和外框完整性核对。

交付前记录 `W,H`、`B`、`w,h`、`margins_LTRB`、alpha 状态和内容核对结果。实际内容比例必须精确、四边距离必须相等；模板内部边框对齐允许的抗锯齿容差不能借用于内容比例或透明边距。画布比例仅记录，不作为 2:1 合格条件。

以下任一情况均不得交付为合格成品：实际内容非严格 2:1；四边透明留白不等距或没有正数留白；只检查画布比例；假透明；拉伸正文/图标；裁掉内容；依靠大块无意义空白或额外测量边框凑尺寸。
