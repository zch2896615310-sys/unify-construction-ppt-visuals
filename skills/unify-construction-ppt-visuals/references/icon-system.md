# 工程 PPT 统一视觉标识系统

## 1. 触发判定

先生成 `icon_plan`，字段为 `module -> icon_mode -> icon_id/thumbnail_subject -> semantic -> color_role`。满足任一条件时不得使用 `none`：

- 三个及以上重复模块、步骤、阶段或里程碑；
- 设备、机具、材料、构配件、样品、措施、工法或资源清单；
- 施工区、楼层、班组、专业、共享资源之间的对应关系；
- 并列内容仅靠文字难以快速区分。

连续正文、精确矩阵或确无稳定图形隐喻时可声明 `icon_plan: none`，并记录原因。不能以“避免混用图标库”为理由整页省略。

`icon_plan` 只决定模块识别标记，不决定是否需要关系图或机制图。即使 `icon_plan: none`，只要 `visual_reasoning_plan.diagram_opportunity` 为 `required` 或 `useful`，仍应按内容生成相应的非写实关系图、机制图、因果链、流程或数据图。反过来，若关系图为 `required`，若干互不连接的图标或编号卡不能替代它。

## 2. 模式选择

只允许以下两种主要模式：

- `semantic-line`：抽象流程、阶段、组织、施工区、楼层、班组、风险、管理动作和不可由外观稳定识别的概念。
- `realistic-thumbnail`：材料、设备、样品、构配件、家具、机具和产品类别；当真实外观能让读者更快识别或比较时优先使用。

物理对象清单达到 3 项以上时，默认使用 `realistic-thumbnail`，除非源页已经提供一套被用户认可的专属矢量图标，或对象外观高度相似导致缩略图无法区分。抽象流程不得为了“更真实”改用无意义照片，精确矩阵不得为了“丰富”塞入装饰性缩略图。

一页可以在不同层级使用不同模式，例如栏目标题使用 `semantic-line`，10 个材料卡使用 `realistic-thumbnail`；因为角色不同，这不属于混用。同一组同层级卡片、同一条流程或同一系列对应槽位只能使用一种模式。

## 3. semantic-line 固定资产与几何

默认图标源：`assets/icons/construction-line-icons.svg`。

- 视框：`24 24`。
- 线条：无填充、圆角端点/连接、1.8px 等效线宽。
- 常规颜色：`#005BAC`；施工机械/分区可用唯一工程橙 `#F59E0B`；完成/验收可用 `#2E9B65`。
- 图标容器：同页统一为浅蓝圆角方形或蓝色圆形，44–56px；不得混用两种容器。
- 同层级图标位置固定：标题左侧或卡片左上角，二选一并冻结。
- 每个主要模块最多一个图标；图标不替代文字，不承担精确数字表达。

## 4. realistic-thumbnail 固定语言

- 主体：单一材料/设备，或能表达类别的最小组合，不放无关道具。
- 背景：白色或透明感抠图底；不得使用完整施工场景冒充小图标。
- 机位：统一约 3/4 视角；板材和卷材可使用统一轻微俯视，整组不可跳视角。
- 光影：自然中性棚拍光，柔和接触阴影，清晰轮廓，不过曝，不悬浮。
- 容器：同层级使用相同 1:1 或近方形容器，主体占容器 68%–82%，统一内边距和裁切。
- 色彩：保留物体真实材质色；自然色不计入界面辅助色数量。卡片、边框和数字体系继续由中建蓝主导。
- 品牌：不得出现商标、包装文字、水印、型号铭牌或虚构品牌。用户提供的事实照片含品牌且必须保真时，仅在内容账本明确登记后保留。
- 连续性：同一系列冻结缩略图的视角、光向、阴影强度、主体比例和容器位置；后续页面只替换对象。
- 来源：有用户照片时优先保留并统一裁切、色温和背景；无照片时允许 ImageGen 生成中性的代表性物料抠图。

推荐材料映射：

| 语义 | thumbnail_subject |
|---|---|
| 涂料 | 无品牌白色涂料桶与滚筒 |
| 实木复合地板 | 三片错缝叠放的木地板样板 |
| 石材 | 大理石/莱姆石/岩板样块 |
| 瓷砖/岩板 | 两到三片陶瓷砖样板 |
| 木饰面/PVC 覆膜 | 木皮卷、木饰面板与踢脚线小组合 |
| 不锈钢/铝合金 | 金属板、收口条和型材小组合 |
| 铝板/铝扣板天花 | 方形铝扣板与冲孔铝板样片 |
| 墙布/皮革/软包 | 墙布卷、皮革卷和软包小样 |
| 银镜 | 立放的无框银镜样片 |
| 玻璃 | 两到三片夹丝/艺术/钢化玻璃样片 |

## 6. 页面实例化

- 设备措施页：若以操作逻辑为主，使用 `semantic-line`；若以设备识别、配置或数量对比为主，使用 `realistic-thumbnail`。照片存在时优先把照片裁成统一缩略图，不再叠加第二个同层级图标。
- 材料/构配件工程量页：默认 `realistic-thumbnail`。材料名称、数量和说明仍为精确信息，缩略图只帮助识别，不得用图像替代文字或数字。
- 进度页：每个阶段一个阶段图标；日期仍使用唯一强调红，图标保持中建蓝。
- 施工区页：两张施工区卡使用同一个 `zone` 图标，依靠区名和辅助色区分；班组条目使用固定 `crew` 图标；并行、流水、共享保障分别使用 `parallel`、`flow`、`shared`。
- 同一 `series_key + page_type` 的 `icon_plan`、`icon_mode`、标识顺序、尺寸、容器与坐标属于模板指纹，不得逐页调整。
- `risk-analysis-measures-series-v1` 固定把“分析”映射到 `measure`、“措施”映射到 `plan`；两个标题使用同样大小与底板体系，不得根据页面内容更换放大镜、盾牌、灯泡等临时图标。

## 7. 验收

以下任一情况为硬失败：触发页面整页无视觉标识；主要模块缺标识；未声明 `icon_mode`；标识与语义不匹配；同一标识表示多个无关概念；同层级混用线性/实心/卡通/3D 玩具/写实模式；线性图标的线宽、底板、尺寸或位置明显漂移；写实缩略图的视角、比例、光向、阴影、背景或容器明显漂移；缩略图带无来源品牌、文字或水印；使用彩色 emoji 代替图标。
