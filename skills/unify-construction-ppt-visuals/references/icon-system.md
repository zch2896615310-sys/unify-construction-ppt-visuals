# 工程 PPT 统一图标系统

## 1. 触发判定

先生成 `icon_plan`，字段为 `module -> icon_id -> semantic -> color_role`。满足任一条件时不得使用 `none`：

- 三个及以上重复模块、步骤、阶段或里程碑；
- 设备、机具、措施、工法或资源清单；
- 施工区、楼层、班组、专业、共享资源之间的对应关系；
- 并列内容仅靠文字难以快速区分。

连续正文、精确矩阵或确无稳定图形隐喻时可声明 `icon_plan: none`，并记录原因。不能以“避免混用图标库”为理由整页省略；使用随 Skill 提供的图标资产。

## 2. 固定资产与几何

默认图标源：`assets/icons/construction-line-icons.svg`。

- 视框：`24 24`。
- 线条：无填充、圆角端点/连接、1.8px 等效线宽。
- 常规颜色：`#005BAC`；施工机械/分区可用唯一工程橙 `#F59E0B`；完成/验收可用 `#2E9B65`。
- 图标容器：同页统一为浅蓝圆角方形或蓝色圆形，44–56px；不得混用两种容器。
- 同层级图标位置固定：标题左侧或卡片左上角，二选一并冻结。
- 每个主要模块最多一个图标；图标不替代文字，不承担精确数字表达。

## 3. 固定语义映射

| 语义 | icon_id |
|---|---|
| 满堂架/脚手架 | `scaffold` |
| 移动式操作平台 | `platform` |
| 剪刀车/升降设备 | `scissor-lift` |
| 移动电源 | `power` |
| 充电式机具 | `tool` |
| 集中充电房 | `charging` |
| 电动斗车/运输 | `cart` |
| 电动叉车 | `forklift` |
| 施工准备/计划 | `plan` |
| 样板施工 | `sample` |
| 测量放线 | `measure` |
| 基层施工 | `layers` |
| 湿作业/防水 | `droplet` |
| 饰面安装 | `finish` |
| 固装/点位安装 | `install` |
| 调试/细部处理 | `tune` |
| 验收/交付 | `acceptance` |
| 建筑/施工区 | `building` / `zone` |
| 楼层 | `floors` |
| 班组/人员 | `crew` |
| 两区平行施工 | `parallel` |
| 区内流水施工 | `flow` |
| 共享保障资源 | `shared` |

若语义不在表中，先选择最接近的稳定上位概念；只有确实无法表达时才新增图标。新增时必须同步本表与 SVG sprite，且不得改变既有 icon_id 的含义。

## 4. 页面实例化

- 设备措施页：每张设备卡一个专属设备图标；照片存在时图标放在标签带，不遮挡设备主体。
- 进度页：每个阶段一个阶段图标；日期仍使用唯一强调红，图标保持中建蓝。
- 施工区页：两张施工区卡使用同一个 `zone` 图标，依靠区名和辅助色区分；班组条目使用固定 `crew` 图标；并行、流水、共享保障分别使用 `parallel`、`flow`、`shared`。
- 同一 `series_key + page_type` 的 `icon_plan`、图标顺序、尺寸、容器与坐标属于模板指纹，不得逐页调整。

## 5. 验收

以下任一情况为硬失败：触发页面整页无图标；主要模块缺图标；图标与语义不匹配；同一图标表示多个无关概念；同页混用线性/实心/卡通图标；线宽、底板、尺寸或位置明显漂移；使用彩色 emoji 代替图标。
